ABOUT THIS MOCKUP

Version 1, invented data only. MyCase Bookings on the phone, as a screen of its own. It shows the same thing as the desktop panel: how many surgeries the deal's surgeon is booking, a simple bar chart for each type of surgery (Hip, Knee, Shoulder, CMFT), month by month. Graphs only, no editing.

  • Phone 1, the way in: a MyCase Bookings row on the deal screen next to Chatter and Campaigns, saying how many cases in the last 12 months. Tapping it slides the screen in (0.4 s), with its own “‹ Back to deal” bar.
  • Phone 2, the screen: one card for each type the surgeon does. Each has the number of cases in the last 12 months in big figures, Primary and Revision under it, and a bar chart: the 12 whole months and this month so far (lighter, not in the total, marked *), with the number above each bar, primary under revision. CMFT is never split.
  • A surgeon with several hospitals for a type (Hip here) gets a dropdown above the chart: “All hospitals” first, then each hospital with its cases. Choosing one redraws the chart and the figures; the desktop does the same with a list. With one hospital there is no dropdown and the card says “all at Mater Hospital”. Try the Hip dropdown.
  • Phone 3: the two things a rep can be told instead of charts: no Primary HCP on the deal, or no surgeries with usage items in the last 12 months.

Not shown: how the cases are counted (a surgery that has happened, has at least one usage item, is not a demo or non-billable one; revision is Type A01) since it is the desktop's rule, unchanged, and the numbers are read with the existing Apex (getBookings), no new server code. Charts are drawn by the same code as the desktop's, sized to the phone. Colours are the desktop's (primary blue, revision orange, CMFT teal). Theme for dark.
