Two changes to the campaign view in Pipeline, as Robert described them on 2026-11-25: a ROSA tick between Risks and Include Closed in Maintain, and a Type column in plain text saying Opportunity, Risk or ROSA. Invented data.

  • Part 2 is Report. The Type column is on to start with. Press Columns and untick Type to take it off, tick it to bring it back.
  • The Type is plain text, not a coloured chip (Robert, 2026-11-25). Not shown: the value chips and tiles above the list, Widen search, light mode.
