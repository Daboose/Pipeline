ABOUT THIS MOCKUP

The My Case Bookings screen with live charts and the suggestion panel: it first says what we found (the problem), then what you can do. The page below is the size of your window; the screen inside it scrolls, so you can judge scrolling. Invented data only (Dr Example Surgeon).

Try it:
  • The chart takes a third of the width and the suggestion panel two thirds, side by side and about the same height. The knee panel shows its two hospitals next to each other.
  • In either layout, click the choices in a panel, press Review changes, then Confirm. Nothing is written until Confirm. Start again resets.
  • Resize the window to see the charts redraw. Light / Dark switches the theme.
Worth knowing: a knee (or hip) usage holds one company per line, so ZB and a competitor cannot both sit on the same line. Not shown yet: CMFT and shoulder, the rest of the deal flyout behind it.
