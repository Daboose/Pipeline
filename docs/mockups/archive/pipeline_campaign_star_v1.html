About this mockup

Is this what you meant? The Opportunities list on the Pipeline home screen, with:

  1. A gold star after the surgeon's name when the deal is in one or more campaigns, beside the existing green rep priority star.

The rows show every combination: neither star, green only, gold only, and both. The green star follows each person's heading colour setting (lime here). Dark and Light buttons are in the top bar. Nothing else changes.

Not changed: the small tags in the list itself (current, needs update, very old) are still lower case. Say if they should be proper case too.

Not shown: the Risks list would carry the same star. The ROSA list has no surgeon column, so it is not drawn.
