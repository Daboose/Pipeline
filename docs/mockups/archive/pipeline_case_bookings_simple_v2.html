ABOUT THIS MOCKUP

My Case Bookings, graphs only, with the choice you made: the screen decides for each portfolio how many hospitals the surgeon operates at. One hospital: no list, the graph takes the whole width and the hospital is named in the heading line. More than one: a hospital list on the left with All hospitals on top (the default); click a hospital and the graph shows only its cases. Invented data only (Dr Example Surgeon).

Try it:
  • Hip starts with one hospital (Hollywood Private Hospital): no list, the hospital is named in the line under the heading.
  • Press Hip: add a second hospital to see Hip change to the list with All hospitals on top. Press it again to go back.
  • Knee has three hospitals: click through them, then click All hospitals to go back.
  • The Light mode button switches the colours.
Not shown yet: Shoulder and CMFT sections (the same, one per portfolio the surgeon operates in), surgeries with no hospital recorded (they would appear as a "No hospital recorded" entry, which with one real hospital makes two entries and so brings the list), the rest of the deal flyout.
