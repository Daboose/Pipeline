ABOUT THIS MOCKUP

Pipeline's lists already show a star beside the surgeon when a deal is a rep priority (in your chosen heading colour) and a gold star when it is in a campaign. This page shows a third star for a state priority, in four ways, and the same line added to the legend above the list (dashed box). The four lists use the real list styles; the data is invented.

  • The three stars always sit in the same order after the surgeon's name: rep priority, state priority, in campaign.
  • Try it: the first row has a rep star only; the second a state star only; the third has all three; the last has a state star and a campaign star.
  • Try it: switch Dark and Light, then each Heading colour, and see which version stays easy to tell from the rep star.
  • Not shown yet: the mobile list (it has no state star today either), and the ROSA list.
