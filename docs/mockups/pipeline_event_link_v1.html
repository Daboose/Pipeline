PIPELINE Pipeline Opportunities & Risks Accounts
ABOUT THIS MOCKUP

Version 1, invented data only. It shows three things Robert asked for on 2026-11-06: (1) the new Event choice in Change selection, which can be saved inside a named filter; (2) the Event field in the deal flyout; (3) the stage path with both ends (the winning stage in green and the losing stage in red) next to what it does today.

  • The Event box only exists for people who can see the field. Switch This person to “Cannot see the field” to see the screens without it. Nothing shows, nothing is explained.
  • Events apply to opportunities and ROSA deals, never risks. Switch off Opportunities and ROSA in Change selection and the Event group greys out. Open a Risk in the flyout and the Event field is gone.
  • Try it: on Change selection choose “Has an event”, type “hip” and pick an event, press Apply, then “Save as filter”. Then switch the person to “Cannot see the field” and open the saved filter.
  • On Deal flyout pick a different deal type, change the event and watch Save changes light up. Click a path step to move the stage.
  • On Stage path pick a stage, and compare today’s path with the two-ended one.

Not shown yet: how “No event” counts appear in the list, the Event column in the lists, the phone view. The 59 events in UAT are real, the names below are invented.
