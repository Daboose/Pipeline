Pipeline: choose the stage view

Comparison page, not a Pipeline screen. Invented numbers only.

ABOUT THIS PAGE Each type (Opportunities, Risks, ROSA) gets its own stage component on the main screen. These are the three ways to draw it, shown on the same invented numbers so they can be compared. The number of deals and their value sit inside each stage. THE THREE VIEWS
  • 1. Funnel, width follows the deals: the stage with the most deals is the widest; a stage with no deals is narrow.
  • 2. Funnel, even steps: the stages step down evenly from the first to the last, whatever the numbers. Looks like a classic funnel.
  • 3. Compact bars: a plain list with a bar beside each stage.
TRY IT
