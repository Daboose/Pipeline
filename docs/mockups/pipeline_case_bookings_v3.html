ABOUT THIS MOCKUP (version 3)

The My Case Bookings panel: for each type of surgery the surgeon does, the surgeries per month over the last 12 months, split into primary and revision, with the 12-month total, side by side, and a check against the Surgeon Usages. Changes in this version: side by side is the only layout (chosen by Robert), and usages that are more than 10% out now come with a suggestion and a button that adjusts them, so the user cannot get the numbers wrong. All names and numbers are invented.

Try it:
  • Knee and shoulder (Dr Rao): the knee usages say 100 but 64 were booked. Press Adjust usages to these bookings: the usage line moves and the check turns to "accurate". Shoulder lists only a competitor, so it asks for the usages to be checked.
  • No usages at all (Dr Lindqvist): red chip, red warning on each graph, and a suggestion per hospital with a button that creates the usages.
  • Hip and knee (Dr Fraser): hip is accurate, knee has no usages. Knee only (Dr Hartley): usages far too low. CMFT only: no primary or revision.
  • Within 10% of the cases booked is accurate. Reset puts everything back. Dark and Light both work.
Not shown yet: the Open Surgeon Usages button (does nothing here) and the phone layout. Creating or adjusting makes one usage per hospital for the portfolio (a hip usage gets stems and cups with the same cases), with the record type for the person's country. Demo and non-billable surgeries are not counted; the lighter last bar is this month so far.
