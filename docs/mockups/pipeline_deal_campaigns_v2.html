ABOUT THIS MOCKUP

Version 2, invented data only. It replaces version 1. Robert corrected the first version on 2026-11-06: sales reps do not use the Pipeline screen, they use the standard Salesforce record page of the deal on a desktop or a phone. So the Campaigns control is a button on that record page (a quick action) that opens a small screen where the rep adds the deal to campaigns. Pipeline users get the same screen in Pipeline's own deal flyout (press “Pipeline deal flyout” below): same component, a second place to open it.

  • Try it: press Campaigns next to Edit in the top right of the record. A dialog opens. Flick a switch to put the deal in that campaign and back to take it out; it saves straight away. Close with Done and look at the “Campaigns” list on the right of the page, which now shows where the deal is.
  • Only the right campaigns are offered: active, covering the country of the deal's owner, covering the deal's portfolio, and with the deal's Primary HCP (the surgeon) as a member. “Campaigns are not offered” lists each one left out and why.
  • Switch the deal below: an Opportunity, a Risk and a ROSA deal all work the same way (all three have a Primary HCP); the fourth has no Primary HCP yet, so there is nothing to match.
  • Phone: choose Phone for the Salesforce mobile app version: the same screen, full screen, with big switches.

How it would be set up (as APAC Events did it): two launchers for the same screen, one for desktop and one for phones, shown by device on the existing record page. Changing the record page and its layout changes something that already exists, so it needs Robert's explicit sign-off at the time. Not shown: the campaign manager's side (Campaign Management is a separate mockup). The phone has not been tried in the Salesforce app.
